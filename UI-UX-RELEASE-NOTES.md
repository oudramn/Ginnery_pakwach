# The Ginnery UI/UX polish release

## What changed
- Increased paragraph sizes and line spacing, constrained copy measures, and prevented awkward word breaks across the guest journey and supporting pages.
- Improved persistent navigation, responsive CTA targets, visible keyboard focus, and mobile readability.
- Reworked the story chapter transitions with active background scaling, a staggered headline landing, active controls/ARIA states, and an explicit reduced-motion fallback.
- Added restrained hover/light behavior to the experience cards and ambient linework to the rooted section using the 10K Websites effects engine unchanged.
- Removed the intrusive floating motion-review launcher; the motion study remains in the footer.
- Kept all existing booking, request, admin, language, currency, and backend behavior intact in source; no claims were made that live hotel integrations exist.

## Verification
Automated HTML/JavaScript checks and local page smoke tests are recorded after test execution. External Unsplash/Google Fonts assets require network access in the preview.
